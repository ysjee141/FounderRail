# Knowledge Catalog

공식 원문, 적용 조건, 검증일과 만료일이 있는 Knowledge Card만 활성 지식으로 사용한다.

공통 자료는 무엇을 확인해야 하는지를 설명하고, `company/`는 현재 제품이 실제로 무엇을 하는지 기록한다.

`team knowledge check`가 source hash, freshness, Card 참조와 active module coverage를 검사한다. `team knowledge compile`이 생성한 fresh·verified Card만 역할이 일치하는 Agent에게 주입된다.
